# Historic Cyber Attacks That Shaped Modern Cybersecurity

A research project on seven landmark cyber incidents, from the first self-spreading program in 1971 to the ransomware outbreaks of 2017. For each incident, it covers the timeline, attack method, impact and lessons learned.

Completed for **Cybersecurity Fundamentals / Ethical Hacking** at **NIIT Enugu**.

📄 **Full report:** [Cyber_Attack_Assignment.pdf](report/Cyber_Attack_Assignment.pdf)

## Incidents covered

| Year | Incident | Type | Key lesson |
|------|----------|------|------------|
| 1971 | Creeper | Experimental self-spreading program | Programs can move across networks without user action |
| 1986 | Brain | Boot sector virus | Removable media can carry malware |
| 1988 | Morris Worm | Internet worm | Patch software, use strong passwords, coordinate incident response |
| 2000 | ILOVEYOU | Email script worm | Social engineering exploits trust; show full file extensions |
| 2001 | Anna Kournikova | Email script virus | Beginners can build malware with toolkits; filter script attachments |
| 2017 | Equifax breach | Data breach (unpatched Apache Struts) | Patch quickly, keep asset inventories, encrypt and segment data |
| 2017 | WannaCry | Ransomware (EternalBlue) | Update systems, keep offline backups, retire outdated software |

## Key takeaways

1. **Patch fast.** Unpatched software enabled both Equifax and WannaCry.
2. **People are part of the attack surface.** ILOVEYOU and Anna Kournikova succeeded because users trusted familiar-looking messages.
3. **Every major attack drove progress.** They led to antivirus tools, CERTs, cybercrime laws and modern security practices.
